# 数据来源方案

已核查官方接口能力；尚未下载全样本，也没有发布实证结果。

## 首选与备选

- **CSMAR 学校订阅**：正式研究首选，与开题报告一致。需核对学校导出权限、含退市股的历史覆盖、ST 状态、复权收益、月度市值和账面市值比，以及公开展示聚合结果的许可。
- **Tushare Pro**：可用于自动采集验证。`stock_basic` 提供上市与退市日期、状态；`daily` 提供未复权日线；`adj_factor` 提供复权因子；`daily_basic` 提供换手率、市值、PB。股票列表及部分指标接口要求 2000 积分起，具体按账户实际权限测试。密钥只放本地环境或部署 Secrets。
- **AKShare**：公开接口交叉验证与演示路径。`stock_zh_a_hist` 能获取 A 股历史行情；正式研究前须验证退市样本、复权口径、历史完整性与接口稳定性。

## 数据合同

股票代码、交易日期、复权日收益率、收盘价、复权因子、上市日、退市日、所属板块、ST 状态、换手率、流通市值、账面市值比。另需市场、规模和价值因子的月度序列。每个字段记录来源、原始名称、单位、提取日期及缺失率。

## 小样本验证门槛

先选一只存续股票、一只退市股票验证历史记录和复权；再用一个完整年度检查主键重复、停牌、ST、样本覆盖与极端值。通过后按日期分块采集，原始和清洗结果分开保存。公开仓库只放代码、字段说明和获准公开的聚合结果。

本机 Tushare 配置已通过只读接口测试：退市列表返回 344 条，其中 285 条符合沪深 A 股常规代码格式且在 2025 年前退市；`000001.SZ` 在 2025 年 1 月的日线、复权因子和日指标各返回 18 条。接口可用不等于全样本研究已验证。

`scripts/probe_tushare.py` 将存续股和退市股的小样本下载至 Git 忽略的 `data/raw/pilot/`，记录日期、缺失值和主键审计。它只从环境变量读取令牌。
