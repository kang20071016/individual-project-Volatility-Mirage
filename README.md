# Volatility Mirage

A 股低波动异象互动研究平台。默认展示 Tushare Pro 的 100 股分层探索样本；另有模拟模式。访客可以切换深色或暖米白主题，比较板块和组合，在预测挑战里做历史情景推演与小游戏，再向“小股”追问。

## 本地运行

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

Windows 上也可双击 `start-preview.bat`，然后打开 `http://localhost:8503/`。本地预览依赖运行中的终端，关闭终端或重启电脑后需重新启动；`localhost` 不是可长期分享的线上地址。

左侧可切换页面颜色、数据模式、年份和多个板块。真实样本仅开放已计算的 60 日历史波动率与等权组合；其他波动率口径和权重变化只在模拟模式提供，页面会标明。网站合并为“发现与实验”“预测挑战”“证据与数据”“小股研究室”四页；术语有短解释，可选择对照组与滚动观察窗口。

预测挑战用当前筛选后的历史月度 D1－D10 收益差重复抽样，展示未来 1～6 个观察月的情景中心值与 80% 抽样范围，并用只看过去数据的历史回看展示误差。它不含实时行情，也不能预测今天 A 股指数走势。小游戏让访客根据前三个月猜下一月哪组领先，揭晓后可看实际差值；没有金钱或交易功能。

## 真实样本与方法

`data/public/portfolio_monthly.csv` 是可公开查看的月度十分位组合汇总，不含个股原始记录。`data/public/metadata.json` 记录下载日期、固定抽样种子和样本量。构造步骤：

1. 从 Tushare 上市与退市记录中，筛选 2021 年底前已上市、2022 年后仍在样本期的沪深 A 股；分层抽取主板 50、创业板 25、科创板 25 只股票。当前名称包含 ST 的股票被剔除。公开汇总保留了抽样结果，原抽样种子因包含个人信息已移除；重跑脚本会使用新的公开种子，得到另一份探索样本。
2. 以每日收盘价乘复权因子构造复权价格，在月末利用最近 60 个交易日的日收益标准差（不少于 45 日）计算年化历史波动率。
3. 每个板块和月份单独按波动率分成 10 组，计算**下一个自然月份**的复权月末收益，再形成组内等权组合。跨板块汇总时按每组股票数加权。
4. 计算 D1－D10 月度收益差、年度算术和、滚动 12 个月算术和，以及 Bartlett 核、最多 6 阶滞后的 Newey–West 均值标准误与正态近似区间。

当前样本形成 45 个月的组合收益、约 9.7 万条日行情记录。**这是探索性研究，不能直接代表全 A 股低波异象。**固定的 100 股队列有抽样误差；当前名称筛选不能重建历史 ST；未做市值加权、交易成本、风险因子调整或全市场覆盖。复现时使用本机 `TUSHARE_TOKEN` 运行 `python scripts/build_research_sample.py`，个股数据不会提交到 GitHub。

## 研究助手（DeepSeek）

“小股”支持自由输入、多轮追问、快捷提问和按当前筛选条件生成的小型收益表。聊天输入框紧接消息末尾；回答以流式文字呈现，默认简洁，需要时再展开。模型会读取当前参数和统计量，并区分真实探索样本与模拟演示。访客无需注册或输入 API Key。未配置模型服务时仍可使用明确标注的内置解读模式。

项目维护者上线前只需配置一次：

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key。
2. 在 Streamlit Community Cloud 的应用设置 → Secrets 中保存 `DEEPSEEK_API_KEY = "你的密钥"`。本地运行时，也可设置同名环境变量或使用被 Git 忽略的 `.streamlit/secrets.toml`。
3. 重新打开应用，研究助手会从内置解读切换为 AI 对话。不要把密钥提交到 GitHub，也不要在页面上显示密钥。

本地可运行 `python scripts/configure_deepseek.py`，在终端的隐藏输入提示中粘贴密钥，脚本会写入 Git 忽略的 `.streamlit/secrets.toml`。公开部署时只在 Streamlit Cloud Secrets 中设置。项目本身不限制聊天次数，也不设发送冷却；单条输入最多 1000 字，单次输出最多 700 token。公开部署时应在 DeepSeek 平台设置预算并限制访问者，否则任何访客都可能消耗额度。

应用调用 DeepSeek 的 `deepseek-flash` 模型，使用官方 Chat Completions 接口。API 用量可能收费；[查看官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)。密钥由服务器读取，访客无需输入。

“数据体检”页读取本机 `data/raw/pilot/audit.json` 和两只股票的探针 CSV，展示 Tushare 字段审计与真实复权价格路径。此目录被 Git 忽略，云端部署默认不会显示本地记录。两只股票不足以支持低波异象推断。运行探针时，先在本机环境设置 `TUSHARE_TOKEN`，再执行 `python scripts/probe_tushare.py`。

研究路线：数据与样本审计 → 波动率指标 → 十分位分组和下月收益 → 统计检验 → 稳健性分析 → 有依据的 AI 解读。

详见 [数据来源方案](docs/data-sources.md)。
